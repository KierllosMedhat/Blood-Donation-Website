# Blood Donation Management System

## Overview
A web application designed to manage blood donors and patient requests. The system provides secure access, controlled workflows, and a user-friendly interface.

## Tech Stack
- ASP.NET MVC
- C#
- SQL Server
- Entity Framework
- HTML, CSS, Bootstrap

## Features
- Secure user authentication
- Donor and patient management
- Controlled access to sensitive data
- Responsive user interface
- Form validation and error handling

## Architecture
- MVC Pattern
- Layered application structure
- Entity Framework for data access

## How to Run
1. Clone the repository
2. Configure SQL Server connection
3. Run database migrations
4. Start the application from Visual Studio

## Future Improvements
- Add role-based authorization
- Improve UI/UX
- Add reporting and analytics
